# External Resources (Online Documents)

This folder is dedicated to external documents consulted for the thesis and the **Making Change** project (institutional reports, central bank notes, working papers, public articles).

## Filing Rules

For every document or link added here:
1. State the **exact source**, **author/institution**, **publication date**, and **URL**.
2. Clearly separate **academic sources** (listed in `docs/REFERENCES-ACADEMIQUES.md`) from **institutional or market sources** (listed here).
3. Never upload copyrighted documents with restricted distribution or confidential data.
