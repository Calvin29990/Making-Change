# Anonymized Data and Interviews

This folder is dedicated to field data and interview summaries (banks, DFIs, project sponsors, corporates) **after full anonymization**.

## Strict Rules Before Adding Any File

In accordance with banking professionals' requirements and confidentiality standards:
- **No proper names** (individuals, banks, funds, clients, counterparties).
- **No indirect identifiers** (exact project name, exact contractual amount enabling identification, exact transaction date).
- **No personal data** (email addresses, phone numbers, named job titles).
- Use generic identifiers (e.g., `Interview_Bank_01.md`, `Infra_Project_Africa_A`).
