A hedge manager is a Python file

auditable in a minute

Each manager receives a HedgeView — years, capacity, the shock being played, the spot rate with its provenance, the hedged rate, the cost, the covenant, and a dscr_with(coverage) callable — and returns a coverage plus the reasoning. It never does the loan arithmetic itself, so it cannot disagree with the tested engine.

To add one: subclass Manager in desk/managers.py, set key, name, tagline, file, implement propose, and register it in MANAGERS. It appears in the menu on reload. No build step, no plugin API.
